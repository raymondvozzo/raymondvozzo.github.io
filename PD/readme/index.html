How this site works

Which file to change for which job, and how to put the change online.

The short version

Almost everything is driven by data files, not by the pages themselves. Each fact lives in one place, and every page that needs it reads it from there. Change the file, upload it, and the pages update.

The discipline electives (Level 1 to 4) are not listed anywhere. They are worked out automatically: every course in courses.csv at that level that is not marked core.

courses.csv: the columns

ColumnWhat goes in it
Course CodeNo spaces, for example MATHX203. This is how every other file refers to the course.
Course NameThe title.
level1, 2, 3 or 4
semester1, 2 or 1, 2 (both). Boxes in the schedules only accept courses offered in their semester.
Prerequisite course(s)Codes joined by AND / OR, with brackets where needed, for example (STATX200 AND STAT2003) OR (STATX302). Codes that are not in this file (like MATH1022) are fine: the tree and the schedules ignore them.
Prerequisite note(s)Free text for grades, unit counts and so on. Shown to the reader but not checked.
majorcore, applied, pure, statistics or discipline. Sets the colour everywhere, and core courses are left out of the discipline elective lists.
offeredy or n: is it currently offered? Courses marked n are shown dashed and dimmed, and give a warning if chosen in a schedule.

When you save from Excel, choose CSV UTF-8 so accented characters survive.

The major-course spreadsheets: the layout

Keep the file names exactly level2.xlsx, level3.xlsx and level4.xlsx, and keep the layout:

  • Row 3 has the major names across the top: UNS, PMTH, APPM, STAT, DATS. The words Pure, Applied, Stats / Statistics and DS / Data Science are understood too.
  • Row 4 has the column labels under each major: Course Title, Course Code and (Levels 2 and 3) Notes.
  • The courses follow from row 5. The code is what counts: it must exist in courses.csv. The title is only a label.
  • Notes is optional. A note starting with Compulsory marks a course that is a fixed box in the schedules (so it is left out of that major's choose-from list and shown first on the Major courses page). Other notes, like Group A, are shown next to the course.

The settings block in schedule/index.html

Open schedule/index.html in a text editor and scroll to the bottom. Each major has an entry like this (shortened):

"pure":{ "majorClass":"pure", "label":"Pure", "title":"Pure Mathematics",
  "std":[ [[1,["L1D","STATX100","MATH1004","CC"]],[2,["MATH1005","MATHX104","COMP1002","CC"]]], …year 2, 3, 4… ],
  "mid":[ …the same, with the semesters in mid-year order… ] }
  • Each year has two rows, written [semester, [four boxes]]. The Year 4 rows have three boxes.
  • A course code (MATH1005) is a fixed box.
  • These short names are choose-a-course boxes: L1D L2M L2D L3M L3D L4M L4D (Level 1 to 4 discipline elective or major course), W1 and W2 (WIL), FE (free elective) and CC (Common Core).
  • Take care with commas and brackets. If the schedule page goes blank after an edit, a bracket or comma is usually missing.

Putting a change online

  1. Edit the file on your computer.
  2. Upload it to the repository, in the same folder and with the same name as the old one, replacing it.
  3. Wait a minute or two for GitHub Pages to publish.
  4. Hard refresh the page (Ctrl+Shift+R, or Cmd+Shift+R on a Mac). Browsers keep old copies of these files, and this is the most common reason a change does not appear.

When something looks wrong

What you seeWhat it means
An orange notice at the top of a schedule: "…not in the prerequisite tree and were skipped"A spreadsheet lists a code that is not in courses.csv. Fix the code in the spreadsheet, or add the course to courses.csv.
An orange notice: "…spreadsheets could not be loaded"A level…xlsx file is missing, misnamed or in the wrong folder.
An amber row with ⚠ on the Major courses pageThe spreadsheet's code does not match the title in courses.csv, or the course is not in courses.csv. The message says which.
"Could not load…" on any pageThe page was opened as a file from your computer (open it from the website instead), or a file it needs is missing.
The page looks like an old versionHard refresh. If it still does, check that every changed file was uploaded.
A ⚠ on a box in a scheduleNot an error in the site: it is the schedule checker. For example, a prerequisite is missing earlier in the plan, or the course is not offered in that semester. Click the box, or see "Things to check" under the schedule.

A checklist for the start of each year

  1. In courses.csv, update the offered column, and any changed semesters, prerequisites or new courses.
  2. If the majors changed, update level2/3/4.xlsx.
  3. If a program schedule changed, update the settings block in schedule/index.html.
  4. Upload the changed files, hard refresh, and open each major in the schedule page. Every schedule should start with no ⚠ boxes, and no orange notice should appear.
  5. Check the Major courses page for amber rows.
